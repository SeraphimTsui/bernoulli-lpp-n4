固定三个占据点的无限反例族——复现与审查

路径：gamma_n=R U² R U^(n-2) R^(n-2)；pi_n=U² R² U^(n-2) R^(n-2)。
模型：恰好三个非端点为1，其余为0；所有并列最优路径都算。
范围：解析证明覆盖每个整数 n>=4，不证明独立Bernoulli全p单调性。

运行（Python3标准库，无第三方依赖）：
  python verify_sparse_dp.py
该脚本重算 n=4,...,11 全部三个占据点配置；它独立使用排序后的
三点最长链动态规划与路径位掩码。对每个n，比较差值以及证明中的
六种分组贡献。机器验证支持人工可检查的组合证明，但不是形式化证明。

  python audit_geometry.py
该程序从路径步词重新生成顶点集合，不使用稿件的共同点公式构造输入；
直接逐点检查n=4,...,30的局部点、共同路径、反链、矩形和链计数。
这是一项有限审查，不能代替稿件中适用于所有n的解析推导。

  python check_poset_identity.py
对一般路径使用不同的计数恒等式 C3=binom(T,3)+binom(T,2)(m-T)-X+Y，
其中X数两点在路径上的三点链，Y数恰一点在路径上的三点反链。
程序通过坐标关系分别计算X、Y，并对n=4,...,11与完整计数比较。
该恒等式及面向全部n的第二种推导见 poset_second_derivation.txt；
它由同一个AI重新组织推导，不应称为独立研究者或独立AI审稿。

  python all_edges.py
  python check_n5.py
对n=5的5984个三点配置和252条路径：格点DP与点偏序动态方法完整
比较全部路径计数；另比较全部560个操作见证的两套生成方式。
这仅是固定k=3的一层，不是n=5的全部2^34个环境。

验证结果：n=4,...,11 的三点层第二份全量重算与前次结果一致；
分类分量分别为 0, -C(n-1,2), 2-2(n-3)^2, 0, 1, 0。
脚本与结果哈希见 SHA256SUMS.txt。注意JSON运行时间字段随重跑变化。

审查：主证明逐项推导局部点、共同路径点和其他点的所有六类；
矩形计数和边界n=4单独核对；两个不同的完整计数算法在n=4,...,11
及两种不同的n=5操作实现一致。该审查与独立实现复算不等于另一位
数学研究者的人工同行评审或定理证明器正式验证。
